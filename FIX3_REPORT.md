# FIX3 — Link Row Repair Report

## Root cause

`css/fix1.css` had competing legacy and later grid rules for route, next-page, contact, and social rows. The text track could shrink while the chip occupied its own grid track, and `overflow-wrap:anywhere` / `word-break:break-word` allowed words to fragment instead of preserving normal wrapping. The social chip therefore did not stay at the card edge. The localized homepage also used a different route-row child structure, and UZ/RU next-page markup used translated class names and plain anchor text, so the shared selectors did not apply consistently.

## EN / UZ / RU differences corrected

All three languages already referenced the same root-absolute stylesheet set with matching cache queries; no language-specific CSS rules were found for these components. The UZ and RU homepage route rows had different child markup from EN, and their next-page containers had translated class names (`rejalar-page` / `дальше-page`) with no `.row-copy`. These now use the same tags, classes, and attribute-name structure as EN. The English components carry `data-review="reviewed"` where UZ/RU carry `data-review="needs-native-review"`; the attribute names match, while values and visible text remain language-specific. The strict structural audit compares tags, classes, and attribute names, excluding text and attribute values.

UZ internal action labels use `SAHIFANI OCHISH`; RU uses `ОТКРЫТЬ СТРАНИЦУ`; EN uses `OPEN PAGE`. External contact rows use translated action wording followed by the destination platform, e.g. `OPEN ↗ GITHUB`, `OCHISH ↗ GITHUB`, and `ОТКРЫТЬ ↗ GITHUB`.
